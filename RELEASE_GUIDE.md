## 1. Опубликовать место

1. Откройте `BattleAdminPanel_v11.rbxlx` в Roblox Studio.
2. Выберите **File → Publish to Roblox As…**, создайте новый опыт и назовите его `BATTLE BUT WITH ADMIN PANEL`.
3. Дождитесь сообщения, что публикация прошла.

## 2. Настроить игру (Creator Dashboard → ваша игра)

- **Basic Info.** Загрузите иконку `GameIcon.png` и обе обложки. Жанр — Strategy или Fighting, устройства — все.
- **Описание** (можно вставить как есть):

  > Build your army, fight other players… and every 2 minutes someone gets the ADMIN PANEL! Type ANY command: "meteor on the enemy base", "heal my army", "summon 3 giants"… Then the roulette decides: EXECUTE it, or EVERYONE ADDS to it!
  > Строй армию, сражайся — и каждые 2 минуты кто-то получает АДМИН-ПАНЕЛЬ! Пиши любую команду, а рулетка решит: выполнить её или все допишут своё!

- **Places → Configure → Max Players:** поставьте `18` (3 комнаты по 6 игроков).
- **Security:** включите **Enable Studio Access to API Services**. Без этого в Studio не сохраняются покупки и тикеты. В опубликованной игре сохранение работает и так.
- **Maturity & Compliance:** заполните анкету. В игре есть пользовательский текст, но он проходит фильтр Roblox (TextService).

## 3. Музыка заставки

Аудио `132472169476353` должно быть доступно этой игре. Проверьте это в Creator Dashboard → **Development Items → Audio → ваш трек → Permissions**: там должен быть ваш опыт (или трек должен быть публичным).

## 3a. Админ-панель (словарь команд + Gemini)

Как понимается команда:
1. **Встроенный словарь** (`AdminCommands`). Если все слова команды ему известны, команда выполняется сразу после рулетки, без ИИ. Полный список готовых команд на русском и английском лежит в `ADMIN_COMMANDS.md`.
2. **Gemini** (`AdminBrain`). Команды с незнакомыми словами уходят в ИИ. Он получает **то, что игрок набрал**, без решёток. На экране при этом все видят текст после фильтра Roblox.
3. Если Gemini не настроен, выдал ошибку или не ответил за 9 секунд, команду разбирает тот же словарь. Он пропускает незнакомые слова, а если ничего не понял, отклоняет команду.

Правила одинаковые для обоих путей:
- **Можно всё, что есть в игре**, в полную силу.
- **Единственный лимит**: 200 военных на игрока.
- **Нельзя**: то, чего нет в игре; кик, бан и выбивание из раунда; моментальная победа; донат.
- Всё действует только до конца раунда.
- Если не подходит одна дописка, отклоняется только она, и она показывается зачёркнутой.
- Автор команды сам к ней не дописывает.

Выполняет всё только `AdminActions`, и каждое значение там ограничено. Поэтому ни ИИ, ни игрок не могут сделать того, чего нет в списке действий. Весь текст, который пишет ИИ (подпись, причина отказа, объявление), проходит фильтр Roblox.

Настройка Gemini:
1. **Creator Dashboard → игра → Secrets:** секрет `GEMINI_API_KEY` с доменом `generativelanguage.googleapis.com`. У тебя он уже заведён.
2. **Game Settings → Security → Allow HTTP Requests:** в файле уже включено, просто проверь.
3. **Studio:** секреты из Creator Dashboard работают только на настоящих серверах. Для Play-теста добавь ключ в **Game Settings → Security → Secrets** под тем же именем.

Ошибки ИИ пишутся в Output с префиксом `[AdminBrain]`.

## 3b. Бесплатные тикеты: промокоды и сундук за лайк

**Промокоды.** В лобби под кнопкой SHOP есть кнопка CODES: она открывает окно ввода кода. Каждый код даёт 1 ADMIN TICKET, один раз на аккаунт.

| Код | Где спрятан |
|---|---|
| `NOOB` | табличка прямо у спавна |
| `METEOR` | табличка на задней стене магазина |
| `GIANT` | плоский камень в траве, в лесу на дальнем приподнятом краю острова (юго-запад) |
| `FREEZE` | на вершине башни из ящиков (запрыгнуть по ступенькам), западнее сцены, где воины дерутся с гигантом |
| `SECRETADMIN` | плот на воде за забором, в дальнем северо-восточном углу: видно, только если посмотреть вниз с края |
| `BATTLE` | для описания игры, работает **7 дней** с первого запуска опубликованной игры |

- Коды хранятся только в серверном скрипте `DonationServer`, игроки не могут их прочитать.
- Если хочешь, чтобы `BATTLE` закончился в точную дату, впиши unix-время в `BATTLE_EXPIRES_AT` там же.

**Сундук за лайк.** Сундук стоит слева от магазина, перед ним золотой круг.
1. Встаёшь в круг: появляется окно «поставь лайк и добавь в избранное, потом перезайди».
2. После перезахода (не раньше чем через минуту) в круге появляется кнопка CLAIM, она даёт 1 ADMIN TICKET.
3. Награда даётся один раз на аккаунт.

Проверить сам лайк или избранное игра не может: у Roblox нет такого API. Поэтому защита держится на перезаходе, минутной задержке и одной награде на аккаунт.

## 6. Вставить ID в игру

1. В Studio откройте **ReplicatedStorage → ArmyRoundShared → DonationCatalog**.
2. Замените `id=0` на ваши числа:

   ```lua
   {key='VIP',kind='Pass',id=123456789, ...
   {key='Admin',kind='Pass',id=123456790, ...
   {key='Ticket1',kind='Product',id=1234567, ...
   {key='Ticket3',kind='Product',id=1234568, ...
   {key='Ticket7',kind='Product',id=1234569, ...
   {key='Ticket10',kind='Product',id=1234570, ...
   {key='Ticket20',kind='Product',id=1234571, ...
   ```

   `price` можно не трогать. Магазин сам подтягивает настоящую цену из Roblox.
3. Снова выполните **File → Publish to Roblox**.

Пока ID равен `0`, в опубликованной игре товар показан как `SOON`, а в Studio — `TEST` (бесплатная тестовая выдача).

## 7. Проверка перед открытием

- **Покупки в Studio** (Play): с настоящими ID Roblox показывает тестовое окно покупки, Robux не списываются. Проверьте:
  - VIP и ADMIN дают теги и тикеты в раунде;
  - тикеты прибавляются в кошельке магазина.
- **Телефоны:** Test → Device (эмулятор телефона). Проверьте заставку, магазин и зум двумя пальцами в раунде.
- **Несколько игроков:** Test → Clients and Servers → 2–3 игрока. Проверьте:
  - комнаты 0/6;
  - админ-панель: ник цветом и текст команды, рулетка;
  - «все дописывают».
- **Открытие для всех:** Creator Dashboard → игра → **Make Public**.

## Владельцы игры (OWNER)

В `DonationCatalog` есть список владельцев:

```lua
Catalog.Owners={'zoy0m','mm2garry'}
Catalog.OwnerUserIds={}
```

У этих игроков:
- над головой в лобби большая надпись **OWNER**;
- в чате тег `[OWNER]`;
- VIP и ADMIN включены сразу;
- все тикеты в магазине бесплатные: кнопка `FREE`, тикеты сохраняются.

Ник сверяется без учёта регистра. Для надёжности можно также вписать числовые UserId в `OwnerUserIds`: ник можно сменить, а UserId — никогда. UserId виден в ссылке профиля: `roblox.com/users/<UserId>/profile`.

## Как устроены донаты в коде (для справки)

- `DonationCatalog`: список товаров и правила (VIP +1 тикет, ADMIN +10 тикетов и +20% шанс).
- `DonationServer`:
  - проверяет владение пассами;
  - принимает покупки продуктов через `ProcessReceipt`, каждый чек учитывается один раз;
  - хранит тикеты в DataStore `BattleAdminVault_v2`.
- `Perks`: выдаёт перки и тикеты раунду.
- Магазин открывается кнопкой с короной справа на экране (в лобби).
